# Website-Catat-Uang
Saya membuat website catat uang ini, karena menurut saya tidak banyak website atau pun aplikasi catat keuangan mudah digunakan dan kurang percaya apakah data disimpan dengan aman. Jadi saya memilih membuat sebuah website yang dijalankan pada localhost, agar cuma seseorang yang menjalankan localhost, yang dapat membuka data keuangan sendiri.
